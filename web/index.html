Search your videos the way you remember them.

Reelcall indexes your library on your own machine. Describe what you saw or heard. It returns the timestamp, a thumbnail, and a clip you can play.

$ uv tool install git+https://github.com/bamiboy237/reelcall

Then run reelcall. Requires FFmpeg and Docker.

    How it works

    Stays on your machine
    Videos, indexes, and the model run on your computer. Your library lives in a folder you choose.
    ./data · --data-dir
    Windows, not whole files
    Each video becomes 8-second windows that overlap by 4 seconds. A moment never falls between two cuts.
    8 s window · 4 s stride · 1 frame/s
    Three embeddings per window
    EmbeddingGemma 2 embeds the frames, the audio, and both together. It runs on the CPU.
    visual · audio · combined · 768 dims
    Search in plain words
    Describe a scene or a sound. You get ranked moments with timestamps, thumbnails, and clips you can play.
    / search · ⏎ play · f filter
    A queue that recovers
    Jobs run through a local queue. Failed jobs retry, and interrupted jobs pick up again when the workers restart.
    PostgreSQL · up to 3 attempts
    Terminal first
    Add, index, search, and play from the terminal UI. Scripts get a CLI with JSON output and an HTTP API.
    reelcall · reelcall -h · --json

    Questions

    What do I need to install?
    uv, FFmpeg, and Docker. On macOS, Reelcall starts Docker Desktop or OrbStack when it needs them.
    Does it need a GPU?
    No. EmbeddingGemma 2 runs on the CPU.
    Where are my videos kept?
    In a data folder inside the directory where you launch Reelcall. Run reelcall ui --data-dir to choose another.
    Which formats work?
    Anything FFmpeg can read, including MP4, MOV, MKV, and WebM.
    Can I script it?
    Yes. reelcall -h lists the commands, and --json gives machine-readable output. There is an HTTP API as well.
    Does it work with my coding agent?
    Not yet. An MCP server is in progress. It will let agents like Claude Code search your library and check frames.
