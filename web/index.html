Questions

What do I need to install?

Simply install the package and it guides you through the set up steps and what’s needed

Does it need a GPU?

No, we run the EmbeddingGemma2 model (video variant) which runs fine on most modern CPUs

How does search work?

Each video is cut into n-second windows that overlap by n seconds. Then the frames and sounds are embedded. When you run query, the model embeds your query and finds frames or sounds that closely match.

Where are my videos kept?

You’ll decide an output folder during setup.

Which formats work?

Anything FFmpeg can read: MP4, MOV, MKV, WebM and more.

Can I script it?

Yes. reelcall -h lists the commands, and --json gives machine-readable output. There is an HTTP API as well.
