Reelcall
GitHub Install

Index and search videos by quoting dialogue or describing scenes.

Reelcall builds a permanent index of your videos. You or your AI agents can then find any scene or quote by describing it in plain language.

$ uv tool install git+https://github.com/bamiboy237/reelcall

Then run reelcall. Needs FFmpeg and Docker.

Demo: Reelcall adds a video, indexes it, finds "the girl in a black witch hat", and plays the match at 0:24.

Questions

Does it need a GPU?
No. It runs on the CPU.
Which formats work?
Anything FFmpeg can read, including MP4, MOV, MKV, and WebM.
Where are my videos stored?
In a data folder where you run reelcall. Use --data-dir to pick another.
What if I close the app while it indexes?
Indexing continues. If a worker stops, its job runs again when the worker restarts.
Can I script it?
Yes. Search, index, and inspect print JSON with --json. reelcall serve starts an HTTP API.
