Questions

What do I need to install?

Install the package and FFmpeg. Docker runs the job service.

Does it need a GPU?

No. EmbeddingGemma 2 runs on the CPU.

How does search work?

Reelcall indexes overlapping video sections and compares your query with their frames and audio.

Where are my videos kept?

In the data folder you choose.

Which formats work?

Anything FFmpeg can read: MP4, MOV, MKV, WebM and more.

Can I script it?

Yes. reelcall -h lists the commands, and --json gives machine-readable output. There is an HTTP API as well.
